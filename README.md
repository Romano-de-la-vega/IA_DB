# IA_DB

Application web de démonstration permettant d'interroger une base de données SQL en langage naturel.
L'interface reprend le style graphique du projet original tout en utilisant l'API OpenAI pour :

1. Convertir la question de l'utilisateur en requête SQL.
2. Exécuter la requête sur la base configurée.
3. Interpréter les résultats et renvoyer une réponse textuelle.

Une fenêtre de paramètres accessible depuis l'icône ⚙️ permet de configurer la connexion à la base et de tester celle-ci.
